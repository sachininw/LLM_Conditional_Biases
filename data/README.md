# data/

Intermediate data generated by the test-generation pipeline. These directories are empty placeholders; files are written here when you run the pipeline scripts.

```
data/
├── scenarios.txt         # 200 decision-making scenarios (committed)
├── generated_tests/      # Raw test cases (XML), one folder per bias
├── generation_logs/      # Human-readable logs, one folder per bias
├── generated_datasets/   # Per-bias CSV datasets
├── checked_datasets/     # Manually quality-checked datasets
└── decision_results/     # Standard decision results
```

Pre-generated data from the paper (message bank, conditional decision results) is available at the [project data store](https://www.dropbox.com/scl/fo/a2c75wjso016f743fspvy/ALXH_sTUkvUDSfZCS-3Z3a8?rlkey=xg5wrfjj8207vhqk2ykxyqbn3&st=guv1u25w&dl=0).
